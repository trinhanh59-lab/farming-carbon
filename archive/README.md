# Analysis history

`Analysis_History_2026-10-20.zip` preserves 86 historical scientific files at their original repository-relative paths, plus `FILE_MANIFEST.csv` with each file's size, SHA-256 and MD5. The files are byte-exact to the repository before this cleanup.

The archive contains superseded cumulative-stock models, earlier hedgerow outputs and figure helpers, selected older mixed-model files, and the separate orchard covariance analysis. These are outside the current paper workflow. Current source data, selected analyses, publication assets and required July bulk-density inputs remain in the main folders.

To inspect or rerun an older workflow, extract the ZIP into a separate copy of the repository, preserving its folders. Use the archived instructions and software records for that historical workflow; current entrypoints do not run it by default.
